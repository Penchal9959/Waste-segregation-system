## Original description

The system segregates waste into wet and dry waste, reducing the workload for municipal staff.

Components:
1. Arduino
2. servo motors sg90
3. IR sensors
4. Breadboard
5. connecting wires
6. 12v DC power supply
7. Aluminium foil

Software tools:

1. Arduino IDE
2. Servo Libraries
